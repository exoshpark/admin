로그인한 회사 | 관리자 명

현재 관리자페이지 HTML과 브라우저 localStorage에 저장된 업로드 페이지 HTML 소스코드를 하나의 HTML 파일에 포함해서 다운로드합니다.

전체 메뉴 39개업로드 페이지 3개포함 소스 183.0 KB
다운로드된 파일은 열릴 때 포함된 페이지 데이터를 자동으로 localStorage에 복원합니다. 따라서 다른 브라우저나 localStorage가 비어 있는 환경에서도 업로드했던 페이지가 함께 표시됩니다. 업로드한 페이지가 많으면 파일 용량도 그만큼 커집니다.

포함 대상

페이지 관리에서 저장한 각 메뉴의 HTML 원본, 활성화 여부, 파일명, 수정일, API 키 값을 함께 포함합니다.

항목포함 여부설명
관리자페이지 UI/기능포함현재 실행 중인 관리자 콘솔 HTML을 기준으로 생성합니다.
업로드 페이지 HTML포함localStorage의 exosp_rebuilt_pages_v1 데이터를 파일 안에 내장합니다.
API 키포함Access Key, Secret Key, lang 값을 내장 후 복원합니다.
